# tluely app

All of the Electron + React + TypeScript code lives here. Project docs are in the repo root: [PROJECT.md](../PROJECT.md), [decision.md](../decision.md), [task.md](../task.md).

```bash
npm install
npm run dev        # run with hot reload
npm run check      # lint + format check + typecheck + tests (run before committing)
npm test           # unit tests (Vitest)
npm run format     # auto-format with Prettier
npm run build:win  # build the Windows installer
```
